# @2060.io/credo-ts-didcomm-reissue

Credo-TS module for the reissue/1.0 DIDComm protocol (Ayni Flow Profile 1.0 §6.11): after a restore the holder asks an issuer to reissue a credential; the issuer answers with an issue flow or a problem report.

Part of [credo-ts-ayni-flow](../../README.md); the profile is
[`v4/ayni-flow-profile/profile.md`](https://github.com/2060-io/ayni-spec/blob/main/v4/ayni-flow-profile/profile.md)
in `2060-io/ayni-spec`.

```sh
pnpm add @2060.io/credo-ts-didcomm-reissue
```

Peer dependencies: `@credo-ts/core` and `@credo-ts/didcomm` on the 0.8.0 PR 2704 snapshot line.
